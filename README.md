# Modern Digital Clock

A Sleek, Minimalist **Digital Clock web Application** featuring a modern black and white theme. The project displays real-time hours, minutes, and seconds, along with the full local date.

## Features
* **Live Dynamic Time:** Updates every second in a 24-hour format.
* **Localized Date:** Displays the full day, month, and year based on German localization (`de-DE`).
* **Responsive Design:** Adapts fluidly to all screen sizes (mobiles, tablets, and desktops) using fluid typography.
* **Clean Aesthetics:** Dark UI with soft glows, custom borders, and sophisticated layouts.

## Technologies Used
* **HTML5:** Structuring the core elements.
* **CSS3:** Designing the layout, responsive typography, and glowing dark-mode styles.
* **JavaScript (ES6):** Fetching and updating live time intervals.
